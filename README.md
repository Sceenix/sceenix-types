## What is Sceenix?

Sceenix builds automated, code-driven video tutorials for modern web applications. When your UI changes, your product videos update automatically, eliminating manual screen recording, voiceover retakes, and tedious timeline editing. 

`sceenix-types` provides the standalone public type definitions (`.d.ts`) required to integrate, type-check, and build custom automation scripts or pipelines targeting the Sceenix engine ecosystem with full IDE autocomplete support.

## Installation

Install the package as a dependency or dev-dependency in your automation pipeline or consumer project:

```bash
npm install sceenix-types
# or
yarn add sceenix-types
# or
pnpm add sceenix-types
```

## Core Type Definitions

The package exports robust type definitions covering:

- Engine Configurations: Viewports, resolutions, and rendering settings.

- Pipeline Jobs: Step definitions, UI automation parameters, and asset bindings.

- CLI & CLI Flags: Argument typing for command-line execution and overrides.

- Output Modifiers: Watermark toggles, outro controls, and export format targets.
